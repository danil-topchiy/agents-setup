# Memory

No durable facts have been recorded.

Record only confirmed preferences and lasting project facts the user wants
remembered. Include a source when useful. Keep temporary task status in the
current conversation or project records, and recheck facts that may have changed.
Do not store credentials here.

## Company knowledge

Shared company, client, and project notes live in the `knowledge/` vault;
`knowledge/README.md` is its index. Search the current project, decision, and
source notes before answering. Keep facts and stakeholder preferences scoped to
the company and engagement they describe.
